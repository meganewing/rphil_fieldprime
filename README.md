# rphil_fieldprime

Repository for field priming project with Manila clams (Ruditapes philippinarum) and basket cockles (Clinocardium nuttallii). Project outline for the manila portion of the project can be found [in my notebook](https://meganewing.github.io/mewing-notebook/posts/projects/manilaclam_fieldoutline.html).

**repo organization**

**`data/`** contains data files (eg., survival assay data, raw fluroscence reads, formatted datafiles, etc)

`code/` data analysis

`output/` output from scripts
